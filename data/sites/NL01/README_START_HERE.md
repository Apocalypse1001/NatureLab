# NatureLab Reference Plot NL-01

Готовый набор открытых геоданных реального участка для экспериментов NatureLab с рельефом, дождевым стоком, домом, фундаментом и ливневой инфраструктурой.

## Участок

- Адрес: Buitenplaats Oosterwold 178, 1349 CP Almere, Netherlands
- Кадастровый идентификатор: `AMR04-C-2426`
- Зарегистрированная площадь: `1 120 м²`
- Центр WGS84: `5.31934583, 52.33421731`
- Исходная система координат: `EPSG:28992`
- Вертикальная система высот: NAP
- Рабочая область: `70 × 90 м`
- DTM/DSM: `140 × 180`, шаг `0,5 м`

Главные рассчитанные характеристики находятся в `processed/site_summary.json`.

## Что лежит в архиве

```text
source/       неизменённые открытые исходные данные
processed/    локальные координаты, heightmap, OBJ, CSV, контуры и сводки
simulation/   стартовые конфигурации NatureLab без выдуманной инженерии
scripts/      воспроизводимая сборка производных файлов
docs/         источники, импорт и ограничения
```

## Быстрый старт

1. Скопируйте всю папку `NatureLab_Reference_Plot_NL01` внутрь проекта, например в `data/sites/NL01/`.
2. Не изменяйте файлы в `source/`. Все исправления и проектные решения храните отдельными слоями сценария.
3. Прочитайте `processed/site_summary.json` и `simulation/scene.json`.
4. Для Blender/FreeCAD импортируйте `processed/terrain_context.obj` в метрах, без масштабирования.
5. Для расчёта только внутри участка используйте `processed/terrain_parcel_only.obj` или `processed/parcel_local.geojson`.
6. Для Warp/Three.js используйте `processed/heightmap_16bit.png` вместе с `processed/heightmap_metadata.json`.
7. Для QGIS используйте исходные GeoTIFF/GeoJSON в `EPSG:28992`.

Локальная система пакета:

- начало: юго-западный угол рабочей области `RD (150340, 482880)`;
- `x` направлен на восток;
- `y` направлен на север;
- `z` направлен вверх;
- единицы: метры.

## Важное разделение данных

### Измеренные/официальные данные

- кадастровый контур;
- AHN DTM и DSM;
- ортофотоснимки 2022–2026;
- BGT: здания, дороги, вода, растительность и типы поверхности;
- региональная карта почвы;
- модель глубины грунтовых вод;
- погодные наблюдения KNMI станции 269.

### Производные данные

- заполнение NoData ближайшим валидным значением;
- OBJ-сетки;
- локальные координаты;
- контуры через 0,10 м;
- hillshade;
- рассчитанный средний уклон и направление понижения.

### Допущения, требующие калибровки

- инфильтрация;
- шероховатость Manning;
- размещение нового дома;
- конструкция фундамента;
- ливневые трубы, колодцы и ёмкости;
- проектная вертикальная планировка;
- синтетические ливни.

## Что видно по истории участка

Ортофотоснимки показывают изменение участка: временные строения/работы в 2022–2024 годах, более очищенную площадку в 2025 году и фундамент/строительные работы в 2026 году. Сводный лист находится в `processed/orthophoto_history_contact_sheet.jpg`.

Для сценария «поставить собственный дом» нельзя молча считать текущую площадку пустой. Создайте отдельный сценарий реконструкции поверхности и документируйте, какие элементы удалены или выровнены.

## Первый рекомендуемый эксперимент

1. Загрузить DTM без дома.
2. Создать равномерный дождь `30 мм/ч` продолжительностью 60 минут.
3. Проверить направление поверхностного стока и места накопления.
4. Проверить баланс массы и отсутствие phantom water.
5. Добавить дом отдельным объектом, не редактируя baseline.
6. Добавить крышу, водостоки и проектную ливневку отдельным сценарием.
7. Сравнить глубину воды и расстояние до фундамента до/после.

Готовый промт для продолжения находится в `START_PROMPT_FOR_CODEX.md`.
