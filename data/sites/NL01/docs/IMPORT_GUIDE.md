# Импорт в инструменты NatureLab

## Blender

1. `File → Import → Wavefront (.obj)`.
2. Выберите `processed/terrain_context.obj`.
3. Масштаб `1.0`; единицы сцены — метры.
4. Оси OBJ уже заданы как `X east`, `Y north`, `Z up`.
5. Ортофото можно наложить как текстуру на прямоугольник `70 × 90 м`; PNG row 0 соответствует северу.
6. Не применяйте вертикальное преувеличение к физической геометрии. Для презентации используйте отдельную копию.

## FreeCAD

OBJ импортируется как Mesh. Для точной параметрической работы:

1. импортируйте `terrain_parcel_only.obj`;
2. используйте `contours_0.10m_local.geojson` как основу для построения рельефа либо конвертируйте mesh в Shape только при необходимости;
3. дом создавайте в отдельном документе и связывайте через App::Link;
4. положение дома храните в `simulation/house_placement.json`;
5. не объединяйте дом с исходным mesh необратимой Boolean-операцией.

## Three.js

- Размер heightmap: `140 × 180`.
- Шаг: `0,5 м`.
- Размер рабочей области: `70 × 90 м`.
- Формула высоты находится в `heightmap_metadata.json`.
- PNG 16-bit необходимо читать без преобразования в 8-bit.
- Визуальная вода не является источником физического состояния.

## NVIDIA Warp

Рекомендуемая первая сетка совпадает с DTM:

```text
nx = 140
ny = 180
dx = 0.5 m
dy = 0.5 m
```

Для первого теста используйте shallow-water/height-field схему. Перед уменьшением шага нужно пройти тесты массы, устойчивости и сходимости на исходной сетке.

## QGIS

- CRS проекта: `EPSG:28992`.
- Добавьте DTM/DSM как raster layers.
- Добавьте `parcel_rd_epsg28992.geojson` и BGT GeoJSON.
- PNG ортофото имеют соседние world files `.pgw`.
- Не перепроецируйте рабочие данные в WGS84 для расчёта расстояний.
